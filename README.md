# 주간학습 프로그램

초등학교 주간학습안내(주간 시간표) 자동 편성 웹앱입니다.

## 사용법

1. https://yskang918.github.io/jugan-timetable/ 접속
2. **+ 새 학년 만들기** — 학교 이름 + 학년을 입력하면 방 코드가 생성됩니다
3. 방 코드를 같은 학년 선생님들과 공유하면 모두 같은 시간표를 보고 함께 수정합니다

데이터는 Firebase(Firestore)에 저장되어 브라우저나 기기가 달라도 항상 같은 내용을 봅니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `app.js` | 전체 로직 (설정 · 시수확인 · 전담배정 · 시간표) |
| `style.css` | 스타일 |
| `firebase-init.js` | Firebase 프로젝트 연결 설정 |
| `db.js` | 데이터 저장 계층 — 로컬(LocalDB) / 서버(FirestoreDB) 두 provider를 갈아끼울 수 있는 구조 |
| `mode.js` | 서버 모드로 초기화 |

## 보안 참고

Firestore 규칙은 `rooms` 컬렉션만 열어두고 나머지는 차단합니다. 방 코드를 아는 사람만 그 방의 데이터를 읽고 쓸 수 있습니다. 학생 개인정보는 저장하지 않는 시간표 데이터라 이 정도로 열어두었습니다 — 학생 이름이 들어가는 기능은 추가하지 마세요.
